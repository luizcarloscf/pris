# Basics

What a student needs before working on a space instrumented with cameras, starting from nothing: each guide starts from a fresh Ubuntu install, explains every term before using it, and uses no code of this repository. Read them in order: each one builds on those before it.

<div class="grid cards" markdown>

- **[The terminal](terminal.md)**

    Typing commands: moving between folders, creating and editing files, installing programs, and reading error messages.

- **[Python](python.md)**

    The language from the first line, then a real project with its packages, tests and type checks.

- **[Networking](networking.md)**

    Addresses, ports, names, TCP and UDP, and what to check when a program doesn't connect.

- **[Containers](containers.md)**

    Docker: running a program with everything it needs, mounting files, building your own images, and networks.

- **[Messaging](messaging.md)**

    A message broker between programs: work queues, publish and subscribe by topic, and requests with replies.

- **[Protocol Buffers](protocol-buffers.md)**

    Turning messages into bytes with a shared schema, and changing it without breaking older programs.

- **[Time synchronization](time-synchronization.md)**

    Why clocks disagree, how to keep them together, and how programs should take and match timestamps.

- **[Kubernetes](kubernetes.md)**

    Running many containers on many computers: Deployments, Services and ConfigMaps on a one-computer cluster.

</div>
