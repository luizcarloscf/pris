# Computer vision

Guides to the computer vision behind a space instrumented with cameras. Like the [basics](../basics/index.md), they start from a fresh Ubuntu install and use NumPy and OpenCV, with no code of this repository. Read them in order:

<div class="grid cards" markdown>

- **[Frames and transformations](frames-and-transformations.md)**

    Coordinate frames, rotations and 4×4 rigid transformations: how to name, compose and invert them.

- **[Camera model and calibration](camera-model-and-calibration.md)**

    How a camera turns a point into a pixel, calibrating one with a printed chessboard, and finding where it is.
