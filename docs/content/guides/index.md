# Guides

For students joining the space: each guide starts from a fresh Ubuntu install and uses only standard tools, with no code of this repository. Start with the basics, then computer vision.

<div class="grid cards" markdown>

- **[Basics](basics/index.md)**

    The terminal, Python, networking, containers, messaging, Protocol Buffers, time synchronization and Kubernetes: what any program of the space relies on, from the very beginning.

- **[Computer vision](computer-vision/index.md)**

    Coordinate frames and rigid transformations, the camera model and its calibration, then reconstructing points and objects from several cameras.
